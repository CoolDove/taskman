# TaskMan

A tiny, controller-first "recent apps" card carousel for Android handhelds.

## Why

Android's built-in recents screen is not comfortable with a gamepad. Closing an app or
switching foreground often ends up needing a touch, which feels clunky — and if you dock
your handheld to a TV and play with an external controller, touch is not an option at all.
TaskMan is a small app that fixes exactly that, you can navigate and close app entirely
with buttons.

## Requirements

- Android 6.0+ (minSdk 23), landscape.
- [Shizuku](https://shizuku.rikka.app/). This is important, you need to install and config
  this so that TaskMan can get required extra permission.

## Recommendations

### [iiSU](https://github.com/iisu-network/iiSU)

**iiSU** is a visuals-first launcher for handhelds. It's beautiful and handy, I use it on
my machines, it's very good. I studied its visual language (I personally honestly sincerely
guided my AI assistant to learn it) and reused it here, so hopping between iiSU and TaskMan
stays **immersive**.

### [KeyMapper](https://github.com/keymapperorg/KeyMapper)

As the name says, it's a key mapper. I use KeyMapper to map a button to launch TaskMan. TAht
makes me totally forget the system built-in recent screen. Also for immersiveness.
